# Question 1: Explanations & Observations

* **Command:** `whoami`
    * **Explanation:** I executed this command to display the currently logged-in username. The system confirmed the active user is `rushikesh`.
* **Command:** `groups`
    * **Explanation:** This command was used to list the groups the current user belongs to. It showed that the user is part of the `rushikesh` and `users` groups.
* **Command:** `echo $SHELL`
    * **Explanation:** By echoing the `$SHELL` environment variable, I verified the default command-line interpreter being used, which is `/bin/bash`.
* **Command:** `pwd`
    * **Explanation:** The "print working directory" command was used to verify my current location in the file system, outputting `/home/rushikesh`.
* **Command:** `ls -lh`
    * **Explanation:** I ran this to list all contents of the current directory in a human-readable format. It displayed standard user directories like Desktop, Documents, and Downloads.
* **Command:** `ping -c 4 google.com`
    * **Explanation:** This command tested outbound network connectivity by sending exactly 4 ICMP echo requests to Google. The output showed 0% packet loss, confirming active internet access.
